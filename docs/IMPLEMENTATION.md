# 已批准的实施基线

2026-09-06 用户确认完整 V1 方案。该文件是执行范围，不是已完成功能声明。

独立私有 OpenAcad 仓库；全中文；无需登录；本机 IndexedDB 草稿与 `.openacad.json` 项目；自制可编辑模板和模拟数据。所有图表入口按家族/变体去重，研究事实不等于功能上限。

阶段 0 固化 54 卡/52 原入口和 29 树图层×3布局研究。阶段 1 通用编辑器与柱/线/棒棒糖/堆叠/饼/散点/柱线组合，首次公开部署。阶段 2 描述统计、误差/分布、相关和聚类矩阵、PCA/PCoA/NMDS/CCA/RDA/Mantel、回归与检验。阶段 3 集合/关系/地图与生信专业图。阶段 4 三种树布局、完整树编辑及注释。阶段 5 全量验收。不得把第一批发布称为完整 V1。

每个模板必须提供真实 SVG 渲染、两套有效示例、中文校验、实际生效的控件、中文帮助；逐一验收输入替换、样式、错误、SVG/PNG/PDF/EPS 独立打开与项目往返。树图额外逐层验收。预览使用自己的渲染器，原站图片仅用于研究。

技术：React/TypeScript/Vite/D3；FastAPI/RQ/Redis；Python 唯一负责描述统计、标准化、通用距离/聚类、PCA，R stats/mgcv/vegan/ape/ade4 负责专业统计；Inkscape 导出。固定依赖和算法参数。任务需要不可猜测凭据，计算/导出白名单，两个执行槽，完成后的输入/结果最多保留一小时。

统计遵循批准方案：样本 SD n−1、R-7 分位数、观测须端；Gaussian KDE/Scott 默认；Welch 默认独立 t，配对按 ID；明确 P 校正与有效样本数；标准化只做一次；PCoA 负特征值诊断；NMDS 禁止隐藏变换；CCA 是典范对应；Partial Mantel 必须 X/Y/Z 严格对齐、Pearson；不把示例或预计算结果称为真实计算。

增强：误差原始与汇总两种输入、SD/SE/CI、KDE/分箱显式区分、百分比堆叠、柱线双轴、色觉友好配色、排序、文字注释、裁切与字体检测。

部署：香港 47.243.4.247，独立 /opt/openacad、Compose、端口与 Nginx；openacad.xyz HTTPS。Linux CI 构建测试，保留上一版本，维护模式/任务排空、成对前后端切换、失败回滚。保护同机现有服务。

不纳入：账号、云端长期项目、AI 生图、序列建树、差异表达全流程、GO/KEGG 富集检索、AB1/KO 附属服务。
