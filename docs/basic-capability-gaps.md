# 基础图表能力与未覆盖项

更新：2026-09-06。实现路径 `web/src/templates/basic/`。25 个模板能够渲染、编辑和恢复项目，但这不表示已经覆盖 ChiPlot 全部控制。

## 已实现

- 柱、分类柱、分组柱、原始或汇总误差柱、分组误差柱、散点误差、实际值与 100% 堆叠、带大组的堆叠、真实双轴柱线、普通与分类棒棒糖、分组折线、误差折线。
- 箱线、分组箱线、小提琴、云雨、峰峦；R-7 分位数，样本 SD（n−1），观测值内的 Tukey 须，SD/SE/95% Student t 均值区间；高斯核密度与分箱频数明确区分。常数数据不能估计 KDE，给出中文提示。
- 饼/环、三种玫瑰形状、雷达、哑铃、普通/分组散点、实际集合成员计算的 UpSet 独有交集。
- 画布/背景/透明、标题与字体、颜色/透明度/图例、类别排序、横纵方向、局部刻度字体颜色粗斜体、旋转、数值范围、自定义刻度和格式、轴位置/偏移、轴标题上下标、网格、右侧标题条。控制仅适用于实际对应几何，例如类别轴没有数值范围。
- 统计输入转换：长表转宽表；配对检验按样本 ID 对齐并拒绝缺配对；汇总均值不能充当原始统计观测。散点消费服务器真实 lm/loess/gam 曲线和置信带。
- 每个模板含自制 CC0 中文模拟数据及第二组有效数据、列级/单元格中文错误。输入格式 csv/tsv/xls/xlsx；根编辑器承担上传、项目、撤销、导出四格式。
- 61 项 Vitest 通过：25 模板的示例/替代数据、SVG 有限几何、错误、项目往返、统计数值基准、真实分析结果曲线、部分样式几何变化。尚未完成每个控制的浏览器逐项验收与所有图片文件打开验收。

## 尚未覆盖，不能宣称完整 V1

1. ChiPlot 各入口的对数坐标、坐标断轴、轴端箭头等全部特殊坐标设置。
2. 每个系列单独的字体/点形状/线形/颜色覆盖、全部原站点符号、每个标签独立拖动（目前图例可拖动；根层文字可编辑）。
3. 条纹/纹理图案填充、原站所有 legend symbol 配置、图层局部背景和命名分组色条。
4. 堆叠柱的组分连接带、完整大组分隔/标题布局；当前大组与类别以联合类别表达，计算和几何真实。
5. UpSet 左侧集合大小子图、空交集显示、全部排序/筛选/颜色布局开关；目前上方非空独有交集柱和集合矩阵可用，最多 12 集合。
6. ChiPlot 每种玫瑰、哑铃、雷达的所有局部格式，以及折线面积层、曲线全部类型、误差标注全部排布；已提供的控制均有实际消费，但不代表原站控制全集。
7. 所有超大字号、长文本、过小画布和大量类别的自动排版验收未完成；实际导出前需检查裁切。SVG 使用显式尺寸与字体，可交给根导出器处理字体。
8. 统计结果当前由根面板显示，基本图内尚未绘制组间显著性括号、字母分组和全套自定义位置；服务器真实结果已可计算。
9. 上传宽表、多工作表与原站原始 JSON 工程的完全格式兼容尚未实现；当前使用文档明确的 OpenAcad 长表和项目格式。
10. 原站柱线入口 404，OpenAcad 的实现为独立设计，不声称还原无法核实的控制。

以上缺口必须在全量 V1 验收前关闭或明确显示为未完成，不应因模板状态 `available`（可以使用）而计为功能对照表全部完成。
