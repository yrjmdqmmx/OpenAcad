## 25 个真实可编辑模板

`bar`、`bar-category`、`bar-grouped`、`bar-error`、`bar-grouped-error`、`scatter-error`、`bar-stacked`、`bar-grouped-stacked`、`bar-line`、`lollipop`、`lollipop-category`、`line`、`line-error`、`box`、`box-grouped`、`violin`、`raincloud`、`ridgeline`、`upset`、`rose`、`pie`、`radar`、`dumbbell`、`scatter`、`scatter-grouped`。

## 数据和计算约定

- 误差原始数据按类别×分组计算均值，样本标准差用 n−1；汇总输入需要均值、SD 和样本量；SE=SD/√n；95% 均值区间使用 Student t 的 n−1 自由度分位数。
- 箱线使用 R-7 分位数；Tukey 须端取 1.5 IQR 内的最外侧实际观测，离群值单独绘制。
- KDE 为高斯核，默认 SciPy Scott 带宽 `SD × n^(-1/5)`，512 个含两端点的等间距网格；可选 SciPy Silverman `SD × (3n/4)^(-1/5)`，并非 R 的 bw.nrd0。前端仅做同定义即时预览，统计权威实现为 NumPy/SciPy 服务，分析面板可复核并保存来源版本；全常数观测不能估计 KDE。
- 分箱使用指定数量的等宽箱；左闭右开，最后一箱包含最大端点；频数轮廓不以平滑样条制造数据。
- 统计权威实现归 NumPy/SciPy 服务。图中的均值、SD、CI、分位数、分箱和 KDE 是同定义的本地即时预览，不能据此声称“服务计算完成”；描述统计及核密度服务复核会单独保留 provenance。推断统计在真实服务执行。长表转宽表时类别×分组成为独立列；配对检验必须有 `样本` 列，并严格按同一 ID 对齐，拒绝缺配对或重复 ID。均值/SD 汇总表不能冒充原始观测。
- 散点回归消费服务返回的 lm、LOESS、GAM 曲线与置信带。仅改样式无需重新计算；数据或统计参数改变后旧结果停止参与预览。
- 原 ChiPlot JSON 工程格式、任意宽表自动识别不是已承诺的互通格式；OpenAcad 明确支持自己的长表和 `.openacad.json` 项目格式。原始输入和图片分别保存。

## 证据

- `web/tests/basic.test.tsx`：61 项；25 模板示例/替代数据/有限 SVG/项目往返/错误及统计数值基准。
- `web/tests/basic-advanced.test.tsx`：22 项，其中 6 组独立 SciPy Gaussian KDE 各 512 点逐点误差小于 1e−12；高级几何、条件控制、真实结果结构消费、CLD 非传递关系、堆叠连接、局部样式、断轴校验、分箱端点等测试。
- `web/src/templates/basic/evidence/browser-advanced.json`：高级柱图标签单步撤销、纹理/断轴/色带、宋体、项目恢复和真实 SVG/PNG/PDF/EPS 下载；另记录树 71 组合。
- `web/src/templates/basic/evidence/browser-statistics.json`：实际服务 Python 3.12.3 / SciPy 1.17.1 的 Welch+BH 结果，三组原始观测、三个两两比较、P 值/字母标注及项目恢复。
- 同目录 `bar-advanced.*` 为实际导出文件；`bar-pdf-opened.png`、`bar-eps-opened.png` 为 Poppler/Ghostscript 独立打开的结果，已目视检查。截图另以 `*-screen.png` 命名，不覆盖图表下载文件。

## 仍需在整站验收中独立判定

正式域名、服务器部署、全浏览器/手机兼容、全部 55 模板的导出矩阵和每个声明控件的整站审计由根任务汇总。这里的模块通过证据不能代替整站验收，也不保证任何任意长文本或用户主动拖出画布的组合均自动避碰。

KDE 独立基准文件：`server/tests/artifacts/basic-kde-reference.json`，直接调用 SciPy 1.17.1 生成，包含 Scott、Silverman、数值 factor、绝对带宽换算以及两种倍率；没有调用前端预览实现生成期望值。

实际服务复核：`server/tests/artifacts/kde-live-check.json` 使用不同样本量两列、Scott×1.6、trim=false，通过真实 HTTP/RQ 服务计算；与独立 SciPy 512 点基准的最大绝对误差为 1.39e−17。KDE 的核带宽使用样本 SD（ddof=1），未截断网格按每列范围加减 3 倍总体 SD（ddof=0）；默认截断至该列观测最小/最大值。
