# 视觉规范

依据本次生成的 `catalog-concept.png`、`editor-concept.png`，采用白色 #ffffff、冷灰 #f5f7fa、正文 #172b3a、强调色 #087f8c、图形辅助色 #eb8972。无背景装饰图与渐变。模板预览由实际 SVG 渲染器生成。

字体使用 Noto Sans SC，系统中文字体作为加载过程的回退。界面正文 14px、表格/说明 12px、导航 15px；页标题 30px，项目标题 16px；图中文字采用自己的可编辑字号。明确为工具产品，图形面积优先。

导航：OpenAcad 开放学术、模板库、本机项目、帮助中心、方法与版本、打开项目。模板页标题“选择一种图，开始探索数据。”，说明“使用示例开始，替换数据，保存可继续编辑的项目。”，名称/用途搜索，分类左栏，三列真实图表预览。

工作台：固定顶栏与项目工具栏；左侧数据/分析/图层，中央可缩放 SVG 画布，右侧画布/文字/图表属性。侧栏为直立面板，宽 300px 与 280px，可调整。保存项目和图片导出是独立按钮。边线 #dce3e8、4px 圆角、无厚重阴影。Lucide 16px 线条图标。按钮明确焦点与禁用状态。

手机：保留品牌、可横向滚动导航；模板两列或单列；编辑数据/预览/设置切换，表格全屏编辑。390px 不横向溢出页面，图本身按比例缩放。

设计必要延伸：模板详情、本机项目、帮助和方法页沿用同一字体、面板与间距体系；用于真实数据角色、误差说明、统计诊断、导出参数和未完成状态的中文文案属于用户已要求的功能性补充。
