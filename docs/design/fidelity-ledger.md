# 界面视觉对照

2026-09-06，通过图片查看工具对照 `catalog-concept.png`、`editor-concept.png` 与 `tests/artifacts/catalog-desktop.png`、`editor-desktop.png`。

| 对照项 | 实际结果 |
|---|---|
| 模板库层级 | 保留顶部导航、中文标题、整行搜索、左侧分类及三列真实图表卡片。白底、蓝灰细边框与青色交互色一致。 |
| 科研图形 | 卡片来自实际 SVG 渲染器；自制模拟数据及默认标题与概念图不同。较密的刻度在缩略图中较小，详情与工作台可完整查看。 |
| 工作台 | 保留数据/分析/图层、中央白色画布、右侧属性以及项目与图片分离按钮。实际支持拖动三栏宽度、缩放、物理尺寸与条件控件，属性分组比概念图更长。 |
| 中文可读性 | 实际黑体/宋体字体与导出使用同字节文件；画布图形、标签与正文目视无明显缺字。 |
| 手机 | 390px 下改为数据/预览/设置切换；通用流程与无横向溢出自动检查已通过。 |

实际截图中的“中文导出验收”为测试时编辑的标题，不是产品固定文案。概念图仅用于布局指导，不作为产品模板或图表计算结果。
