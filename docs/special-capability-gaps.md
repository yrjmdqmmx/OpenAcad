# 矩阵、关系、生信模板的能力与验收边界

核查日期：2026-09-06。源码范围 `web/src/templates/special/`；22 个 OpenAcad 模板。源站对照见 `docs/research/special-source-details.json`。这个数量是 OpenAcad 的可编辑模板数，不能当作 22 个独立 ChiPlot 编辑器；源站对应 20 个唯一入口，二值形状与富集点/柱复用了入口。

## 已实现的实际行为

## 已有证据

- `special.test.tsx`：39 项自动化测试，包括 22 模板的两组数据、有限 SVG、中文逐格错误、项目编解码、实际控件变化、悬空边/环路/越界、原始统计边界、CDD/MEME/MCScanX 原格式和 GC 结果适配。统计结果适配测试使用受控结果夹具，不是端到端统计算法验证。
- `evidence/browser-qa.json`：Chrome 独立上下文实际进入本地 5178 编辑器，22 模板均完成示例、另一组数据、撤销、中文标题修改、实际项目下载与同 ID 项目重开。默认图所有未被显式 clipPath 裁切的文字，屏幕包围盒未越出 SVG 画布。
- `evidence/*.png`：10 种代表模板实际浏览器预览。已目视检查 Mantel、基因簇、富集圈图的中文、几何和边距。
- `evidence/browser-interactions.json`：实际 SVG 下载/重新打开、网络拖动与原格式 UI 的独立验收结果。必须查看每条 result，不以脚本存在代替运行成功。
- `evidence/browser-advanced.json`：行列注释、断轴、动态轨道实际添加/保存/SVG 导出，真实统计 8 次端到端证据单列于 `browser-real-analysis.json`；附带 `.openacad.json` 留存输入、参数、结果及 provenance。
- 公共 App 的“同 ID 项目重开仍显示当前修改”问题由这个浏览器测试发现，根实现增加打开版本后，22 模板复跑通过。
- 所有示例由 OpenAcad 自行生成，CC0-1.0；自然地理底图许可证和来源见 `DATA-SOURCES.md`。未复制 ChiPlot 的模板图片、后台算法或示例数据作为 OpenAcad 生产模板。

## 明确存在的差异与尚未验收项

1. 当前覆盖了上述绘图家族，不能称为与 ChiPlot 每一项按钮和图层完全等价。源站未逐项操作过的上传格式、全部选项、图片导出和项目重开在研究 JSON 中继续标“待核实”。
2. 矩形及圈形行列聚类树、行列分类/数值/文字注释已补齐。注释宽度超过当前画布可用空间会明确报错。可拖动色标及源站每个标签微调按钮尚未逐项对齐。
3. Venn 是 2～5 集合的精确计数 + 非面积比例轮廓，不声称解决面积比例 Venn/Euler 布局。
4. 网络已补齐 circle/cross/diamond/square/star/triangle/wye 七种符号及自环几何。力导向布局只展示输入边，不推断共现网络；源站额外叠加图层仍以逐图研究记录为准。
5. 地图已覆盖五投影和 14 个填充/空心符号。当前底图只含陆地海岸线；行政区数据着色、地址地理编码、自定义 GeoJSON 导入或空间统计不在本次实施范围。
6. 基因簇已补齐可编辑断轴区间、真实坐标压缩和两套箭头；禁止断轴与基因重叠。现有同类别连接并非生物学同源比对；用户需先确认类别含义。源站渐变与其他叠加图层仍需按具体研究记录逐项评估。
7. CDD/MEME 原格式解析结果在内存用于绘图；切回表格模式读取标准化表格，不会自动把解析结果覆盖进用户现有表。重叠区间按输入次序叠加，未自动分层避碰。MEME 支持包含 scanned_sites 的 XML，不执行基序发现。
8. GC 服务结果支持窗口轨道；已有结果模式使用 OpenAcad 明确表结构，不导入 ChiPlot 的私有项目 JSON。圈图已提供动态轨道编辑器，独立数据与设置进入 project.layers；实际轨道数量受画布半径约束，超出时明确提示增大画布或减小轨道宽度。
9. 富集圈图采用明确的九列契约，未声称与源站所有五/六列简写格式直接兼容。不执行差异表达、GO/KEGG 富集或多重检验计算；绘制用户已经算好的结果。
10. MCScanX 原格式是四列简化 GFF，不接受普通九列 GFF3。原格式导入时长度取每条染色体最大基因终点；完整染色体长度需用户在标准化表里提供。不会重新运行 MCScanX。
11. `evidence/browser-real-analysis.json` 已完成圈形聚类、组内/组间相关、四种 Mantel、FASTA GC 共 8 次本地服务真实端到端计算、provenance 与项目保存和 SVG 导出。全部距离/参数组合的数值一致性仍以统计服务测试为准；输入变化后的失效结果隐藏由公共编辑器负责。
12. SVG/PNG/PDF/EPS 是公共导出流程；`Template.formats` 在当前核心契约表示输入格式，不能据此推断图像格式验收。PDF/PNG/EPS 实际文件需等待服务构建完成后验证。当前浏览器包围盒仅对默认示例作保证，任意长标签或极端画布/字体需要导出前再次检查。
