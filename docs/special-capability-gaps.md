# 矩阵、关系、生信模板的能力与验收边界

核查日期：2026-09-06。源码范围 `web/src/templates/special/`；22 个 OpenAcad 模板。源站对照见 `docs/research/special-source-details.json`。这个数量是 OpenAcad 的可编辑模板数，不能当作 22 个独立 ChiPlot 编辑器；源站对应 21 个唯一入口；圆点/方格二值保留两个原页面，富集点/柱复用一个入口。

## 已有证据

- `special.test.tsx`：46 项自动化测试，包括 22 模板的两组数据、有限 SVG、中文逐格错误、项目编解码、实际控件变化、悬空边/环路/越界、原始统计边界、CDD/MEME/MCScanX 原格式和 GC 结果适配。统计结果适配测试使用受控结果夹具，不是端到端统计算法验证。
- `evidence/browser-qa.json`：Chrome 独立上下文实际进入本地 5178 编辑器，22 模板均完成示例、另一组数据、撤销、中文标题修改、实际项目下载与同 ID 项目重开。默认图所有未被显式 clipPath 裁切的文字，屏幕包围盒未越出 SVG 画布。
- `evidence/*.png`：10 种代表模板实际浏览器预览。已目视检查 Mantel、基因簇、富集圈图的中文、几何和边距。
- `evidence/browser-interactions.json`：实际 SVG 下载/重新打开、网络拖动与原格式 UI 的独立验收结果。必须查看每条 result，不以脚本存在代替运行成功。
- `evidence/browser-advanced.json`：行列注释、断轴、动态轨道实际添加/保存/SVG 导出，真实统计 8 次端到端证据单列于 `browser-real-analysis.json`；附带 `.openacad.json` 留存输入、参数、结果及 provenance。
- `evidence/browser-coverage.json`：最终覆盖专项的实际 Chrome 交互与 SVG 导出；含网络自环/边标签与属性映射、桑基渐变、Venn 标签拖动、共线性拖序、富集分类色带、气泡分类色。清除手动位置和拖动项目重开也有实际断言。
- 公共 App 的“同 ID 项目重开仍显示当前修改”问题由这个浏览器测试发现，根实现增加打开版本后，22 模板复跑通过。
- 所有示例由 OpenAcad 自行生成，CC0-1.0；自然地理底图许可证和来源见 `DATA-SOURCES.md`。未复制 ChiPlot 的模板图片、后台算法或示例数据作为 OpenAcad 生产模板。

## 约定项覆盖复核

以已批准 `IMPLEMENTATION.md` 及 `docs/research/comparison.json` 的逐图“specificStyles”为准，上表 22 模板的已确认绘图项已实现。以下是最终复核补齐的项目，不再列为功能缺口：

- 矩形/圈形聚类树；热图、二值和气泡的行列分类色带、数值与文字注释。
- 网络七种符号、按节点分组/shape 列选择形状、边分类/来源/目标着色、边标签、自环、箭头、节点及标签拖动保存。
- 五地图投影与十四种填充/空心符号；基因簇断轴、两种箭头和独立头部尺寸；圈图动态柱/线/点/色带轨道。
- 桑基来源到目标渐变；Venn 集合标签拖动；MCScanX 染色体手动排序；富集 Class 色带；气泡矩阵按行/列分类色。
- 专有注释按字段名读取，支持调整文件列顺序。多个断轴图层相互重叠会明确报错。网络/Venn/共线性提供“清除手动位置”，恢复自动布局或数据顺序。

剩余收尾属于主任务的最新总套件与正式部署。默认 55 模板的 PNG/PDF/EPS 共 165 个文件已经过真实服务和独立解码；服务器使用与浏览器同字节 OTF 字体。15 份复杂图层专项 SVG 的 45 个三格式文件也已全部通过 Pillow/Poppler/Ghostscript 独立打开与触边检查，见 `server/tests/artifacts/advanced-export-matrix.json`，输入 SHA 已与冻结 SVG 对齐。默认矩阵可能随主任务最终总套件刷新，版本以 `docs/acceptance/templates.json` 为准。EPS 涉及透明效果时按背景合并并可能栅格化，逐文件 diagnostics 明确记录。统计全部距离/参数组合由服务测试验证；本模块已有 8 次真实端到端计算。

## 明确的实现差异与数据契约

这些是使用边界，不应混在尚未完成的约定项中：

1. Venn 2～5 集合按真实成员计算精确互斥交集；轮廓为非面积比例示意，不声称面积等于数量。
2. 网络的节点/边注释使用 `nodes.group/shape/label/size` 与 `edges.group/label/weight` 等可选列；不导入源站私有叠加图层文件。网络只展示输入边，不推断共现网络。最多 300 个节点。
3. 注释和动态轨道占用实际画布空间；不足时显示中文错误并要求增大画布或减小轨道。圈图普通数据使用明确表结构，不导入 ChiPlot 私有 JSON。气泡分类模式颜色只表示行/列类别，圆面积仍表示绝对值；图例显示前 6 项，完整标签保留在轴上。
4. 基因坐标为 1-based inclusive，断轴不能触碰基因。相邻簇同类别连接是用户指定类别的对应，不能当作新运行的同源比对。连接相邻簇的对应类别，不生成新的比对结果。
5. CDD 命中+FASTA、MEME XML 和 MCScanX 原文件保留各自文件角色。切回标准化表格不会用解析结果覆盖原表。蛋白重叠区间按输入次序叠加，没有自动分层。MEME XML 需有 scanned_sites；不执行基序发现。
6. 富集图使用明确字段，圈图采用九列契约，不直接接收源站按位置解释的五/六列简写。火山与富集图展示已有统计结果，不执行差异表达/GO/KEGG 检索或富集检验；这是批准方案明确排除的分析流程。
7. MCScanX 接受四列简化 GFF，不是九列 GFF3；原格式染色体范围取最大基因终点，用户可提供真实长度的标准化表。只展示已有共线性区块，不运行 MCScanX。
8. 地图使用公有领域自然地理陆地底图。行政区 GIS 着色、自定义 GeoJSON、地址地理编码、空间统计、源站项目私有格式兼容不在本次批准的实施范围。
9. 三种树布局和 29 树图层由独立树模块交付，不在本文件 22 模板计数内；未遗漏到“特殊模板”之外。

## 源站研究仍待核实的事实

公开源码确认输入/样式存在，不等于逐格式上传、逐个按钮或每张图的项目重开已经在 ChiPlot 实际操作过。精确源站上传接受格式、导出成功、重开行为、每个文字微调/色标拖动选项继续按研究 JSON 标记证据类型或“待核实”；不能把研究未知写成 OpenAcad 已缺失的功能，也不能宣称与源站每项按钮完全等价。

SVG/PNG/PDF/EPS 是公共图片导出；`Template.formats` 表示输入格式。默认示例和专项配置有真实图像验收，任意长标签、极端画布或字体仍要经过公共导出前的裁切检查。所有完成声明以运行后的报告为准，不以测试脚本存在为据。
