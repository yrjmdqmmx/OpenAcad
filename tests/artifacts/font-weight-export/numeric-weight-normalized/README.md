# 650 静态字体匹配修复回归

使用冻结 `export.py` 和两种同源 Regular/Bold 字体，在默认用户、只读镜像、1 CPU/512 MiB 的 Linux Inkscape 容器运行；51 项检查通过（6.27 秒）。这里的 18 份实际输出来自 2 种字体 × 400/650/700 三种字重 × SVG/PNG/PDF。

两种字体的 650 与 700：SVG 字形路径相同、PNG 解码像素 SHA 相同、PDF 使用同一个具名 Bold 字体资源。6 份 PDF 又经本机 Poppler 打开；650/700 的 PDF 预览字节 SHA 也相同，文字可见墨迹均未触及页面边界。400/700 仍有实际笔画增厚差异。

有效 1..1000 数值按现有两张静态字体匹配：<=500 选 400，>500 选 700。处理 `font-weight` 属性、行内样式和样式表声明；声明顺序和 `!important` 保留。`normal`/`bold` 映射为 400/700；`bolder`/`lighter`、继承和变量等上下文值不盲猜。字体宽度、custom property、CSS 字符串和 SVG 正文不改。原始安全检查先执行，外部 URL、data 链接及混淆注释仍被拒绝。

原未归一化的 400/700 验证与线上 1.0.1 记录没有被覆盖。这里只验证本次静态字重修复，不扩大到斜体或全部字体样式。
