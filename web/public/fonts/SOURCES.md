# 中文字体来源

Noto Sans CJK SC Regular 与 Noto Serif CJK SC Regular 来自 notofonts/noto-cjk 官方仓库，使用 SIL Open Font License 1.1。字体未修改，保留完整中文和拉丁字符。

- https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf
- https://github.com/notofonts/noto-cjk/blob/main/Serif/OTF/SimplifiedChinese/NotoSerifCJKsc-Regular.otf

浏览器用同一字体文件渲染；服务端 fonts-noto-cjk 提供同族字体。需避免接收方缺字体时，使用 SVG 文字转曲或已嵌入字体的 PDF。
