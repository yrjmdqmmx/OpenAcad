# 系统发育树工作台验收

更新：2026-09-06。来源是当前公开的 ChiPlot `tvbot.html` 编辑器；三布局为同一树编辑家族。OpenAcad 提供 `tree-normal`、`tree-circle`、`tree-unrooted`，不执行序列比对或系统发育建树。

## 树输入与编辑

- Newick：引号名称、单引号转义、科学计数分支长度、嵌套注释、数值内部支持度和 `[&support=…]` / NHX B 支持度；明确报告缺分号、括号或非法枝长。
- Nexus：TREES 区块、TREE/UTREE、TRANSLATE、引号内分号与名称；当前读取第一棵树（TREE 或 UTREE）。
- phyloXML：命名空间、实体、clade 嵌套、名称/分类学名称、枝长元素或属性、confidence；不加载 DTD/外部实体。
- 节点 ID 唯一匹配注释。改显示名保留 ID；重新导入树后按新树检查原注释；不会猜测旧节点和新节点的对应关系。
- 折叠/展开、删除枝叶、逐个子节点上移/下移、反转顺序、按叶名/叶数整理子树、指定分支比例换根、按枝长升/降序、按叶数降序、编辑名字/枝长/支持度、下载当前 Newick。
- 换根保持叶 ID 和所有叶间路径距离；连续换根生成唯一根 ID。结构写入 `project.layout.treeState`，可撤销和保存恢复。

## 分支与支持度细节

- 原创 SVG 路径覆盖矩形 6 种（直角、圆角、直线、椭圆、横向与纵向贝塞尔）、环形 5 种（不含圆角）、无根 3 种（直线与两种贝塞尔）。动态选项只提供当前布局有效样式。端点形状、分支透明度和线宽独立生效。
- 矩形可从左向右或从右向左，叶名、引导线、注释轨道及年代尺同步；环形可向内生长，叶端内半径可调。多轨道自动为向内中心预留空间，不把用户声明的半径当作裁切框。
- 支持度来源为实际 support、posterior 或数值节点元注释（变量名不区分大小写）。`98/85` 多值节点标签可通过 `support1`、`support2` 读取。缺失值不会冒充 0；后验概率需用户显式乘 100 才按百分比显示。
- 支持度文本提供范围筛选、倍率、小数位、字号/颜色/粗斜体/对齐/偏移；圆点按缩放后值 ≤70 隐藏、(70,90] 灰色、>90 黑色，并可调半径。标注可以拖动，一次拖动产生一步撤销，偏移相对节点存入项目。
- 分支长度文字提供显示倍数、小数位、字体样式、偏移和拖动。它只显示确实提供的枝长，不给缺失长度编造结果。重定根节点可独立显隐。
- 上游能力证据：[官方分支说明](https://1996xjm.github.io/tvbot/user_interface/attribute_main/branches.html)。OpenAcad 路径控制点为独立实现；不声称源站内部计算点逐字节一致。

## 已有时间树输入与编辑

- 支持 Newick / Nexus 的 MCMCTree 时间枝长与 `[&95%HPD={下界,上界}]`，并兼容旧 `[&95%={…}]`。当前 PAML 官方源码明确前者来自 HPDinterval；后者保留“95% 可信区间，原文件未注明类型”，不改写成 HPD。
- BEAST 接收冒号前节点元注释 `height` / `age`、`height_mean`、`height_median`、`height_95%_HPD`、`posterior`；不会把冒号后分支元注释或裸节点名称误当成年代。已有节点年龄与均值/中位数是不同摘要；平均/中位缺项明确沿用原树值。
- 缺失年代仅在具备完整时间枝长和一致相对基准时映射；缺枝长不使用普通树默认 1 推造年代。非数值、空区间、倒置区间、负年代与父子年龄冲突具体定位；不静默截负数为 0。区间不必包含当前目标树点估计，这不自动判为错误。
- 三布局按已有年代真正计算节点位置；原枝长模式保留输入枝长。HPD 在矩形为水平区间、环形为径向区间、无根为局部枝方向区间。无根图不提供误导性的全局绝对年代轴。
- 节点年代、平均/中位摘要、上下界和后验概率可编辑。区间有显隐、颜色、厚度、不透明度、端帽及文字模式；区间数值可乘换算倍率以对齐原树单位，文字有颜色/字号/粗体/偏移。年代文字有倍率、小数位、粗体/对齐/偏移；默认隐藏叶节点年代以减少重叠。所有变化进入项目和撤销历史。
- 内置两个自制 CC0 模拟时间树；不估计分歧时间，不运行 BEAST/MCMCTree，不从单树评估收敛。时间单位、tip-date offset/calendar scale 由原始研究提供，默认明确写“原树时间单位”。
- 原始语义依据：[TVBOT 输入](https://1996xjm.github.io/tvbot/user_interface/attribute_main/data.html)、[TVBOT 年代显示](https://1996xjm.github.io/tvbot/user_interface/attribute_main/nodeAges.html)、[PAML 官方源码](https://github.com/abacus-gene/paml/blob/v4.10.0/src/mcmctree.c)、[BEAST TreeAnnotator](https://beast.community/treeannotator)、[BEAST 节点/分支元注释](https://beast.community/nexus_metacomments)。

## 数据、布局和图片

- 箱线为真实重复观测的 R-7 / Tukey 计算；饼图与堆叠按用户数值计算。序列位置为 1-based 闭区间；MEME 扫描 XML 的 0-based position 转换为 start=position+1、end=position+width。
- 热图、二值、气泡、文本矩阵按 nodeID×列名匹配；重复单元格、缺列、非数字、越界区间、未知节点和无效颜色有明确提示。
- 隐藏或无根布局不支持的图层仍在项目中保留。`treeProjectIssues(project)` 检查全部图层；当前可见且支持的无效层返回 error，隐藏/暂停层返回 warning。根编辑器据 error 阻止导出，不能把跳过无效层的图片当成完整图。
- 三布局、多轨道和图例使用 `requiredTreeCanvas` 确定实际画布，根 SVG/内部 SVG/导出尺寸一致。密集八层时增加右边距会增加实际画布宽度，已测试。
- 有分类/系列/基序注释时才展示图例开关；图例按真实类别绘制。字体为与导出同资源的黑体或宋体。

## 明确边界

- Nexus 多棵树选择器尚未提供；先读取第一棵并在帮助中说明。
- 地质年代尺使用用户给定的年代分段。时间树保留输入的相对年代单位，不自动推断日历年代、校准点、MCMC 收敛或完整后验分布。
- MEME 只读取已有 scanned_sites XML，不发现基序；重组使用明确区间表，不运行重组检测，也未宣称兼容 Gubbins 原始格式。
- 三布局按结构计算位置，节点/分支不是任意自由手绘。非常长的叶名、极大字号和极多轨道仍应检查预览并调整画布/叶名宽度；未声称所有任意组合都自动避碰。
- 原站私有 JSON 项目不作为互通格式承诺；结构、样式和图层完整保存在 OpenAcad 项目文件。

上述边界不会把未执行的统计或未解析的文件伪装为已实现功能；整站及生产部署仍需根任务的独立验收。

- 动态菜单的真实浏览器记录 `evidence/browser-dynamic-options.json` 验证同一项目切换三布局后，分支连接选项严格为 6 / 5 / 3；公共“显示数值”开关显示已有分支长度，并启用其专有格式控件。
